# KKKCreations Website Guidelines

## Project goal

Build a refined, responsive website for KKKCreations, a bespoke tailoring studio in Bhutan. The experience must feel minimal, professional, editorial, and distinctly handcrafted.

## Required stack

- React with TypeScript.
- Use the repository's existing toolchain and conventions when present.
- Use Cormorant Garamond as the primary display and brand typeface.
- The site must work well on desktop and mobile.

## Visual direction

- Use a restrained warm-brown palette with warm ivory and neutral supporting tones.
- Do not use gradients, glowing borders, glowing backgrounds, glassmorphism, or generic AI-style visual effects.
- Prefer disciplined typography, generous whitespace, strong photography, fine rules, subtle texture, and purposeful motion.
- Keep controls, cards, and product listings professional and minimal.
- Treat the supplied landing-page references in the repository and https://institchu.com/ as inspiration, not material to copy.

## Information architecture

The main landing page should include, in this order:

1. Editorial hero / landing section.
2. Separate Men and Women collection entry points that link to their respective collection experiences.
3. Appointment section with fashion-designer-style clothing sketches, location, contact information, and a clear booking action.
4. A grid of selected previous work with polished individual product presentation.
5. A temporary offers section (placeholder offers are acceptable until the client supplies final copy).
6. Awards and acclaim.

The tailoring proposition must be clear: clients can select a KKKCreations design or bring their own design, and the studio will make it to measure in the client's chosen fabric.

## Implementation quality

- Build accessible semantic markup, visible keyboard focus, useful alternative text, and adequate color contrast.
- Respect reduced-motion preferences.
- Avoid layout shifts and oversized dependencies.
- Use responsive images and sensible mobile navigation.
- Keep reusable UI in focused components and keep content/data easy to replace later.
- Verify the finished experience at desktop and mobile sizes.

## Collaboration

- Preserve unrelated user changes.
- Inspect the supplied references before choosing final composition and styling.
- Read and follow the installed `find-skills`, `frontend-design`, and `web-design-guidelines` skills when working on this project.
